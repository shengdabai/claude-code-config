# Codex 网络连接问题解决方案

## 🔍 问题诊断

**错误信息**：
```
stream disconnected before completion: error sending request for url 
(https://chatgpt.com/backend-api/codex/responses)
```

**原因**：无法连接到 `chatgpt.com`，通常是因为：
1. 网络无法访问 OpenAI 服务器（需要代理）
2. 连接超时
3. 防火墙阻止

## ✅ 解决方案

### 方案一：配置代理（推荐）

Codex 使用系统的代理设置。如果你有代理，需要配置环境变量：

#### 1. HTTP/HTTPS 代理

```bash
# 添加到 ~/.zshrc 或 ~/.bash_profile
export HTTP_PROXY="http://127.0.0.1:7890"      # 替换为你的代理地址
export HTTPS_PROXY="http://127.0.0.1:7890"
export http_proxy="http://127.0.0.1:7890"
export https_proxy="http://127.0.0.1:7890"

# 如果代理需要认证
export HTTP_PROXY="http://username:password@proxy.example.com:8080"
export HTTPS_PROXY="http://username:password@proxy.example.com:8080"
```

#### 2. SOCKS5 代理

```bash
# 使用 proxychains 或类似工具
# 安装 proxychains-ng
brew install proxychains-ng

# 配置 ~/.proxychains/proxychains.conf
# 添加你的 SOCKS5 代理配置
```

#### 3. 重新加载配置

```bash
source ~/.zshrc  # 或 source ~/.bash_profile
```

### 方案二：使用 VPN

确保 VPN 已连接并可以访问 OpenAI 服务：

```bash
# 测试连接
curl -I https://chatgpt.com

# 如果返回 200 或 301/302，说明连接正常
```

### 方案三：配置 Codex 使用代理

如果 Codex 支持代理配置，可以在配置文件中添加：

```toml
# 在 config.toml 中添加（如果支持）
[network]
proxy = "http://127.0.0.1:7890"
```

**注意**：Codex 可能不支持直接在配置文件中设置代理，优先使用环境变量。

### 方案四：使用国内替代方案

如果无法使用代理，可以考虑使用国内模型提供商：

```toml
# 切换到智谱 GLM
model_provider = "glm"
model = "glm-4"

# 或切换到 DeepSeek
model_provider = "deepseek"
model = "deepseek-chat"
```

然后设置对应的 API Key：
```bash
export ZHIPUAI_API_KEY="你的密钥"
# 或
export DEEPSEEK_API_KEY="你的密钥"
```

## 🛠️ 快速诊断

运行以下命令检查网络连接：

```bash
# 1. 测试基本连接
ping -c 3 chatgpt.com

# 2. 测试 HTTPS 连接
curl -I --connect-timeout 5 https://chatgpt.com

# 3. 检查代理设置
echo $HTTP_PROXY
echo $HTTPS_PROXY

# 4. 测试通过代理连接（如果有）
curl -I --proxy $HTTP_PROXY https://chatgpt.com
```

## 📋 常见代理端口

| 代理软件 | 默认端口 | 配置示例 |
|---------|---------|---------|
| Clash | 7890 | `http://127.0.0.1:7890` |
| V2Ray | 1080 (SOCKS5) | `socks5://127.0.0.1:1080` |
| Shadowsocks | 1080 | `socks5://127.0.0.1:1080` |
| Surge | 6152 | `http://127.0.0.1:6152` |

## ⚠️ 注意事项

1. **代理必须支持 HTTPS**：Codex 使用 HTTPS 连接
2. **代理必须稳定**：连接中断会导致 Codex 报错
3. **检查代理规则**：确保 `chatgpt.com` 和 `openai.com` 走代理
4. **环境变量优先级**：`HTTPS_PROXY` > `https_proxy` > `HTTP_PROXY` > `http_proxy`

## 🔧 自动配置脚本

创建一个快速配置脚本：

```bash
#!/bin/bash
# 设置代理（根据你的实际情况修改）

# Clash 代理示例
export HTTP_PROXY="http://127.0.0.1:7890"
export HTTPS_PROXY="http://127.0.0.1:7890"
export http_proxy="http://127.0.0.1:7890"
export https_proxy="http://127.0.0.1:7890"

# 测试连接
echo "测试连接..."
if curl -I --connect-timeout 5 https://chatgpt.com &>/dev/null; then
    echo "✅ 连接成功！"
else
    echo "❌ 连接失败，请检查代理设置"
fi
```
